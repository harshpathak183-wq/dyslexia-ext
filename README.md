# 🧠 Dyslexia-Friendly Chrome Extension

A Chrome extension designed to make web content easier to read and more accessible for people with dyslexia.

## 🚀 Overview

Reading content on the web can be difficult for people with dyslexia due to font styles, spacing, text density, and visual distractions.

This extension improves the readability of web pages by providing a more dyslexia-friendly reading experience.

## ✨ Features

- 📖 Dyslexia-friendly text formatting
- 🔤 Improved font readability
- 📏 Adjustable text spacing
- ↔️ Improved line and letter spacing
- 🎨 Better visual readability
- ⚡ Easy to enable and use
- 🌐 Works directly on web pages

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Chrome Extension APIs
